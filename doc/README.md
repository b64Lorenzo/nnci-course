# NNCI documentation

This folder contains the detailed documentation for the NNCI Course Projects and the Windows release package.

## Start here

- [User guide](user-guide.md): install plotting dependencies, choose a run mode, use CLI options, and find generated files.
- [Algorithm and experiment notes](algorithm.md): definitions of `N`, `P`, `alpha`, convergence, capacity, and embedding strength.
- [Development and testing](development.md): configure, build, run tests, navigate the source, and understand release packaging.
- [Troubleshooting](troubleshooting.md): resolve common Python/Matplotlib, missing-file, CLI, and convergence problems.

The repository root [README](../README.md) provides a short overview and quick-start commands. In the packaged release, the same relative links work after extracting the full ZIP archive.

## Package contents

The Windows x64 release ZIP includes:

- `nnci.exe` — C++ command-line application.
- `scripts/plot_capacity.py` and `scripts/plot_strength.py` — plotting helpers used by study commands.
- `requirements-plot.txt` — Python plotting dependency list (Matplotlib).
- `README.md` and `README.txt` — release quick start and documentation pointers.
- `doc/` — these detailed guides.
- `LICENSE` and `THIRD_PARTY_NOTICES.md` — project license and material-scope notice.

Keep the executable and `scripts/` directory in their extracted layout. The application looks up plotting scripts beside the executable, while output folders are created relative to the process's current working directory.

## Scope and limitations

This is an educational Rosenblatt perceptron implementation for Assignment I, not a general neural-network framework. Data are generated by the program; it does not load a user-supplied training dataset. The current implementation runs on the CPU and does not provide CUDA/GPU acceleration.
